# Iot_Energia_Fase_2
Prototipo IoT con ESP32, simulado en Wokwi, para el monitoreo energético de tableros eléctricos. Mide tensión, corriente y temperatura, calcula potencia, energía y demanda, y activa una alarma y desconecta la carga no prioritaria ante exceso de potencia, sobretemperatura o fallos de medición.
